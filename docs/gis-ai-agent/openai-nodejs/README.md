## Sample code

Repository: [`agents/OpenAI-Nodejs/`](https://github.com/mahdin75/gis-mcp/tree/main/agents/OpenAI-Nodejs)

## When to use this path

- Your stack is JavaScript or TypeScript.
- You want native MCP helpers from the OpenAI Agents SDK.
- You are fine managing an OpenAI API key in the agent app.

## Prerequisites

- GIS MCP Server running (HTTP recommended)
- Node.js as required by the tutorial
- `OPENAI_API_KEY` (or as documented in the tutorial)

See also: [HTTP Transport](../../http-transport.md), [Best practices](../best-practices.md).
